# Claude 多开启动器 1.8 使用说明（Windows）

## 安装

运行 `ClaudeLauncherSetup-<版本>.exe`（需 Windows 10 2004 / 19041 及以上）。已安装旧版时会先提示并卸载旧版（只卸载启动器本身，不删账号数据、不退出 Claude），再安装新版。安装到当前用户的 `%LOCALAPPDATA%\Programs\Claude 多开启动器`，不需要管理员权限；开始菜单会出现「Claude 多开启动器」，桌面快捷方式可选。需已安装官方 Claude 桌面版，系统需支持 .NET Framework 4.8 / WPF。

安装程序和启动器目前没有代码签名，首次运行时 Windows 可能提示“Windows 已保护你的电脑”，点「更多信息 → 仍要运行」即可。卸载在“设置 → 应用”中进行，只删除启动器本身，**不会删除任何账号数据**。

## 多账号

- 01 沿用官方默认空间；02 使用 Claude-Second；03～10 使用 Claude-Profile-03～10。
- 「实例管理」只显示本机已有的账号。点「+ 新建实例」创建编号最小的空位，并选择：
  - **直接创建**：立即启动，其他 Claude 保持运行。登录时浏览器回调可能打开其他窗口，登录后请核对身份。
  - **进入登录保护**：需先正常退出其他 Claude；保护期间只允许打开这个账号。
- 点「打开」切回运行中的窗口；点「启动」启动未运行的账号。打开前会先检查该账号的存储（卡片显示“检查中”），通过后才启动或切换。
- 关闭启动器不退出 Claude。各编号独立数据目录不代表系统级安全隔离。

## 账号管理

- 搜索框可按别名、编号（如 `02` 或 `2`）或目录查找；状态可筛选运行中／未运行／处理中（检查或启动中）／异常。读取进程失败时状态显示“未知”。上方统计始终按全部账号计算。
- 铅笔按钮设置本地别名（最多 24 个字，留空恢复默认名称）。别名只保存在启动器自己的 `account-names.json`，不改变邮箱、身份或目录；卡片和表格显示“别名 · NN”。
- 没有别名时，显示该账号本地 Claude Code 配置里的用户名（“用户名 · NN”）：01 读 `%USERPROFILE%\.claude.json`（与终端里的 Claude Code 共用，可能与桌面端登录的账号不同），02～10 读各自数据目录下的 `ClaudeCodeConfig\.claude.json`。只读取用户名一项，不保存、不记录、不导出，也不联网；读不到时显示“账号 NN”。搜索框也能按这个用户名查找。
- 勾选账号（表头复选框可全选当前结果）后点「复制选中路径」，把这些账号的目录逐行复制到剪贴板。筛选隐藏的账号会自动取消勾选。没有批量删除或批量启动。

## 「···」菜单

- 在资源管理器中显示目录、复制目录路径。
- 登录 / 重新登录保护：保护期间只能打开目标账号，其他 Claude 需由你正常退出。启动器不会退出、登出任何账号，也无法拦截浏览器回调。完成登录并核对身份后，点底部「结束登录保护」并确认。
- 删除该实例：二次确认后把该账号的本地目录移到回收站（清空回收站前可恢复）。01 不能删除；运行中（含托盘）、启动中、检查中或登录保护中的账号不能删除。不会注销云端账号或删除云端聊天记录。删除失败会显示“删除未完成”，可再次重试。

## Code 配置状态

实例卡片只显示名称和运行状态；把鼠标停在卡片上可以看到账号目录和 Code 配置状态。「Code 默认」：01 与终端 Claude Code 共用默认配置。「Code 待启动」：未运行。「Code 已指定」：本次由启动器启动，已指定独立 Code 配置目录。「Code 未确认」：从其他入口或旧版启动器启动的实例；保存工作后正常退出，再从启动器启动即可。

## 日志

「日志记录」页的记录保存在 `%LOCALAPPDATA%\Claude-MultiLauncher\launcher-log.json`，重启和更新后保留（保留条数见「系统设置 → 数据与存储」，默认 500 条，超出删除最旧记录）。可按时间（最近 7 天〔默认〕／24 小时／1 小时／5 分钟／本次运行／全部时间）、实例、级别筛选，并全文搜索；每页 10 条，用页码或左右箭头翻页。事件内容可以选中复制，太长时悬停查看全文。「导出日志」写出当前筛选出的全部日志（不只当前页）；「清空日志」需确认，只清空启动器自己的日志文件，不碰 Claude 的日志。「系统设置 → 数据与存储 → 打开本地诊断日志」查看 `%LOCALAPPDATA%\Claude-MultiLauncher\logs`：记录启动器版本、账号编号、进程 PID、进程出现/退出与异常，不读取邮箱、密码、Cookie、令牌或聊天内容，不自动上传。

## 系统设置

页面顶部的分段标签切换六个分类，每类按小标题分组显示。修改先进入草稿，点「保存设置」才生效；切换分类不会丢失草稿，「撤销更改」回到已保存的值，「恢复默认…」只把默认值填入草稿。有未保存的设置时退出启动器会提示保存或放弃。设置只影响启动器自身，保存在 `%LOCALAPPDATA%\Claude-MultiLauncher\settings.json`，不改动任何 Claude 配置或账号数据。

- **常规**：关闭窗口后继续运行（默认开；关闭后，关闭窗口即退出启动器，Claude 继续运行）；显示通知区域图标（默认开；关闭后再次打开启动器即可显示窗口）。
- **启动行为**：「管理开机启动…」单独确认、立即生效，只对安装在 `%LOCALAPPDATA%\Programs\Claude 多开启动器` 的正式启动器可用；登录后只打开启动器，不会启动 Claude。卸载启动器前请先关闭开机启动。恢复上次页面（默认关）、默认页面、本地进程刷新间隔（1／3／5 秒，默认 3 秒）、点击账号时恢复最小化窗口（默认开）。
- **外观**：显示水墨插画（默认开）；显示本地界面用量（默认开，见下方「本地界面用量」）。
- **数据与存储**：显示／复制启动器数据目录、导出已保存的设置（不含账号、项目或凭据）、打开本地诊断日志、日志保留上限（100／500／1000 条）。
- **通知**：窗口内提示（默认开，底部临时提示条）、警告提示音（默认关）、测试按钮。安全确认和错误弹窗不受影响。
- **关于**：版本、更新开关与检查按钮、离线帮助、复制基础诊断信息（只有版本、Windows 版本和联网开关）。

## 本地界面用量

实例卡片右侧的「5小时限额」「周限额」来自 Claude Code 页面上**已经显示**的用量按钮（窗口右下角的「用量：…」）。启动器只读这个按钮上的文字：不点击、不展开、不联网、不调用任何用量查询，也不读 Cookies、登录信息或聊天内容。

- 什么时候读：停在「实例管理」页时，切回启动器窗口、点开实例页或在实例页点一下，各读一次（1 秒内只读一次）。没有定时读取，所以数值不会自动跟着变；想看最新值就切回启动器。
- 需要该账号的 Claude 窗口打开在 Code 页面（首页或某个对话）。窗口隐藏在托盘、在聊天页或登录保护中时读不到，卡片下方会写原因。
- 官方按钮一次只显示一项：五小时窗口进行中显示五小时用量；窗口还没开始（发第一条消息前）显示每周用量。另一项保留上次读到的值和当时的时间，不会推算。卡片上的时间是本机读到的时间，不是服务器时间；悬停可看完整时间和官方的重置说明。
- 第一次读取某个 Claude 窗口时，该 Claude 会开启网页辅助功能（直到它退出），可能稍多占一点 CPU／内存；第一次读取最多等 2.5 秒。
- 读到的值保存在 `%LOCALAPPDATA%\Claude-MultiLauncher\usage-observations.json`（只有百分比、重置说明、时间和用于核对的进程信息）。Claude 重启或账号变化后旧值不再显示。
- 限制：没有核对组织。同一账号里切换组织后，在 Claude 重启前可能仍显示上一个组织的数值。
- 在「系统设置 → 外观」关闭「显示本地界面用量」并保存后，停止读取并删除上述文件。

## 更新

联网检查更新**默认关闭**。在「系统设置 → 关于」打开「允许检查 GitHub 更新」开关，再点「保存设置」才生效。开启后，启动器每次打开时检查一次（只在有新版时提示，失败只记日志），也可以点「检查启动器更新…」或托盘菜单「检查更新…」手动检查。没有定时或后台重复检查。未开启时这些入口不会联网，只提示先开启并保存；有未保存的设置时也不会开始更新。

更新只访问本项目 GitHub Releases（及 GitHub 的下载服务器），不访问其他地址，也不访问 Claude／Anthropic。清单签名、安装包大小和 SHA-256 全部校验通过后，提示“发现新版本”。确认后启动器关闭，安装程序卸载旧版、安装新版并重新打开启动器。不退出 Claude、不改动账号数据。

检查或下载失败时会显示原因，可点「前往 GitHub 下载」手动下载 `ClaudeLauncherSetup-<版本>.exe` 运行。网络不通时可继续使用现有版本。
