# Claude 启动器 1.2.0 使用说明

将「Claude 启动器.exe」解压到自己的可写目录（例如桌面），以普通用户身份运行。需安装官方 Claude 桌面版，系统需支持 .NET Framework/WPF。不要直接在 ZIP 中运行，也不要放入需要管理员权限才能更新的目录。

## 多账号

账号 01 沿用官方默认空间。02 使用 Claude-Second，03～10 使用 Claude-Profile-03～10。首次点击创建，再次点击复用。运行中点击切回原窗口。关闭启动器不退出 Claude。各编号独立数据目录不代表系统级安全隔离，登录跳转和 Cowork 仍需客户环境验收。

## 本地日志

点击「查看日志」打开 %LOCALAPPDATA%\Claude-MultiLauncher\logs。
记录启动器版本、启动/关闭、异常堆栈、账号编号、进程 PID、进程出现/退出、能读取到的退出码以及每 30 秒的存活记录。用户名路径替换为 %USERPROFILE%。不读取账号邮箱、密码、Cookie、登录令牌或聊天内容，不自动上传日志。
保留最近约 10 个日志文件，单文件超过 1 MiB 后轮转。磁盘不可写时日志写入失败不会令启动器退出。
下次闪退后重新打开，点击「查看日志」，把出问题时间附近的日志手动发给维护者。进程退出码或日志突然停止不能单独证明是安全软件、系统或 Claude 缺陷；强制结束/断电可能没有最后的异常记录。

## 云更新

启动时后台检查；也可点击「检查更新」。有新版时按钮显示「更新到版本号」，点击并确认后下载、验证、替换并重启启动器。不会自动退出 Claude，也不会删除账号数据。
下载清单采用 RSA/SHA256 签名，程序额外验证文件大小和 SHA256。签名错误、文件损坏或无法联网会停止更新，现有启动器仍可使用。
更新前保留旁边的 .previous-…exe 备份。新程序启动失败时尝试恢复旧版；如果新进程仍活着但未及时报告就绪，只保留备份并记日志，不强杀它。备份可留作人工恢复。
网络不通时可以继续使用现有版本。旧的无更新功能版本必须手动替换为本版一次。只更新启动器，不更新官方 Claude。
