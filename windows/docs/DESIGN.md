# Claude 启动器界面

用户指定接近 VS Code 的工具界面，面向管理多个本地 Claude 账号的 Windows 用户。核心任务是选择编号、恢复运行窗口、查看诊断日志和检查更新。

本轮只优化既有界面，不增加新业务功能。保留官方 Claude 图标、账号编号、现有独立目录和所有安全确认。采用单列账号表取代两列大卡片；左侧保留当前账号页以及实际可用的日志、更新操作，不制造无功能的导航入口。

## 视觉规范

- 主区 #1E1E1E；侧栏和面板 #252526；分隔线 #303031。
- 正文 #CCCCCC；次要文字 #A8A8A8；强调蓝 #007ACC；运行绿 #89D185；错误 #F48771。
- Segoe UI / Microsoft YaHei UI 用于界面；Consolas 仅用于固定编号。
- 主窗口 960×820，最小 820×560；左栏 190；账号行 52；列表支持纵向滚动。
- 标题 23，账号名称 14，状态及说明 12。键盘焦点使用蓝色边框，悬停提升行背景，禁用操作降低透明度。
- 原生标题栏请求深色，不自绘窗口按钮。底部蓝色状态栏显示平台、运行账号数量和版本。
- 删除确认沿用明确的危险操作文字和默认取消逻辑，面板同步深色。

界面属于日常操作工具，清晰、紧凑、熟悉优先于装饰。离屏截图仅作为尺寸与布局证据，不替代真实输入验证。
