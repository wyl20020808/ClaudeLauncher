# Claude 多开启动器界面（1.6）

与 macOS 1.6 共用视觉方向：用户参考图 `docs/assets/界面.png` 的水墨浅色风格。四个页面：实例管理（账号卡片）、账号管理（统计卡 + 表格）、日志记录（分级日志表）、系统设置（分类导航 + 设置组）。1.2.0 的深色 VS Code 风格界面已替换。

## 视觉规范

- 窗口内容 1080×720，侧栏 272，主区 808；工作区较小时外层滚动。固定浅色，不跟随系统深色模式（插画为浅色）。
- 纸色 #FAF6F0；侧栏 #F3ECE2；正文 #2B2622；次要文字 #6E655C；弱提示 #A59B90；主色（填充按钮）#A8765A；运行绿 #3BAA6E；进行中 #E0A23A；错误 #C9604A。
- 面板为半透明 #FFFDFA，描边 #EDE4D8，圆角 10～16；卡片 #FFFCF7，圆角 14。
- 字体：Microsoft YaHei UI；品牌 “Claude” 用 Georgia；口号用楷体；页面标题优先思源宋体/宋体加粗；图标用 Segoe Fluent Icons / Segoe MDL2 Assets。
- 插画：主区 `background`（靠右铺满，左侧洗白保证可读），侧栏 `sidebar`（底部，顶部渐隐），卡片 `card-1～4` 循环。源文件在仓库 `resources/ui/*.webp`，构建时转 JPEG 内嵌。
- 卡片按钮：运行中“打开”为填充主色，“创建”为主色文字，其余白底描边；禁用时 #EFE9E1 底、#A59B90 字。键盘焦点显示 #B9825F 边框。

## 占位与真实功能

没有数据来源或尚未实现的控件只做静态外观，不可点击：限额进度（标“未接入”）。登录邮箱列固定显示“不读取”。

真实功能：新建实例、打开/启动、“···”菜单、结束登录保护、刷新状态、导出/清空日志，系统设置六个分类（feature/windows-settings 起），账号搜索／状态筛选／别名铅笔／复选框与复制选中路径，日志组合筛选／搜索／分页（feature/windows-accounts-logs 起）。

## 账号与日志

- 搜索框沿用面板样式（左侧放大镜图标、占位文字），筛选为原生 ComboBox；“复制选中路径”无选择时禁用。
- 表头复选框部分选中时为中间态；筛选无结果时表格中间显示“没有符合条件的账号”。
- 日志页（对齐 macOS 1.7.11）：白色圆角下拉筛选（`Pick` 样式，时间框带日历图标）、表头浅色底 #F6EEE4、级别色块（信息 #DDF0E6/#3C8A68、警告 #FCEBD2/#C07A2A、错误 #FCE3DD/#C75F47）；左下为左右箭头与 32×32 数字页码（当前页填充主色，间隔以 … 省略），右侧“共 N 条日志 · 每页显示 10 条”；事件内容是无边框只读文本框，可选中复制。
- `Pick` 下拉样式同时用于账号筛选与系统设置中的选项。

## 系统设置

- 布局对应 macOS 1.7.14：顶部 736×40 分段标签条（常规／启动行为／外观／数据与存储／通知／关于，选中为主色填充），下方 736×504 内容面板，内容区 696 宽、超出时纵向滚动；底部为反馈文字、恢复默认…／撤销更改／保存设置（无改动时禁用）。
- 每个分类按小标题分组为白色圆角卡片（描边 #EDE4D8，圆角 12），每行 60：左侧 16 号主色图标、14 号标题、12 号说明（最多两行，悬停显示全文），行间分隔线 #F1EAE1；右侧为开关（`Switch` 样式 CheckBox，40×20 轨道）、`Pick` 下拉（190 宽）、按钮（按文字宽度，至少 96）或只读值。分组后可跟浅色信息提示框（信息图标 + 说明）。
- 窗口内提示条：主区底部居中，深色半透明圆角条，约 5 秒消失，不拦截点击。

离屏截图（`scripts/preview-ui.ps1`）仅作为尺寸与布局证据，不替代真实输入验证。
