# Claude 多开启动器使用教程

启动器在一台 Windows 电脑上管理多个 Claude 账号。这里只讲四件核心的事，全程本机操作，不向 Claude 发送任何请求。

## 账号：启动、切换、新建

![实例管理页：每个账号一张卡片](guide-instances.zh.jpg)

- **启动**：账号没运行时，点整张卡片。启动前会检查本机网络环境，确认后才打开 Claude。
- **切换**：账号已运行时，点整张卡片会切到这个账号的窗口。Ctrl+1～Ctrl+0 也能打开对应账号。
- **新建**：点右上角“+ 新建实例”，启动器会创建下一个空闲账号，最多 10 个。然后在打开的 Claude 里自己登录。
- **趋势**：侧栏“用量趋势”直接显示各账号的用量曲线。

账号的登录和会话相互独立。退出启动器不会退出 Claude。

## 项目：一份清单，所有账号共用

![项目管理页：添加目录、识别导入和同步会话](guide-projects.zh.jpg)

- **添加目录**：把常用的项目文件夹加进清单。
- **识别并导入**：从各账号的本机记录里找出用过的目录。不读对话内容，不改账号数据。
- **打开项目**：在项目行选一个账号，启动器会打开它并复制路径，在 Claude 中选择这个文件夹即可。

同一个项目请轮流使用，启动器无法检测同时编辑。从清单移除项目不会删除文件。

## 同步会话：换个账号接着聊

额度快用完时，可以把会话带到另一个账号。

- 在项目管理页点“同步会话…”，勾选会话，选目标账号。目标账号要先正常退出。
- 写入的是清理过的副本，不带账号信息，两边不会合并。同步过的会话以最新版本为准：再同步时直接替换另一边的旧版本，旧版本移到回收站。
- 目标账号要已经在启动器里打开过，并正常创建过一次本地会话。用启动器新建的账号做到这一步并退出后，启动器会问一次要不要把其他账号的会话同步过来。
- 目标账号登录过多个账号或组织时，启动器在你点同步后读一次它当前的组织，只写进对应的目录；读不到就不写。
- 打开目标账号时请从启动器打开，侧栏会出现这些会话，标题后带“同步”和时间。第一条消息由你手动发送。

不限 Claude 版本；如果目标账号的会话记录格式变了，启动器会拒绝写入并提示。

## 用量趋势：下一个用哪个账号

![用量趋势页](guide-trend.zh.jpg)

- 打开“用量趋势”页，能看到每个账号近 7 天的 5 小时和周用量曲线。
- 顶部建议条会提示下一个适合使用的账号，也可以直接启动或切换。
- 数值只来自启动器已经观察到的界面显示，启动器不查询 Claude。打开账号的 Claude Code 后才开始记录。
