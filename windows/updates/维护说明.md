服务现已启动。电脑重启后，先运行 updates/启动更新服务.cmd，并确认 Sakura TCP 隧道在线。未新增系统服务、开机任务或防火墙规则。主机睡眠、关机、断网或隧道停止时更新不可用，客户旧版仍能运行。

## 发布新版

1. 修改 src/Updates.cs 中的 AssemblyVersion、AssemblyFileVersion 和 Updates.Version，三处版本保持一致且递增。
2. 在本目录运行 powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1。
3. 运行 powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-install.ps1。集成测试仅用随机临时夹及独立测试密钥，证据保留在临时目录。
4. 检查完成后运行 powershell -NoProfile -ExecutionPolicy Bypass -File scripts/publish-update.ps1。
5. 用启动器检查更新，验证公网发布版本。相同版本不得发布不同内容。

签名私钥保存在当前用户 %LOCALAPPDATA%\ClaudeLauncher-Publisher\signing-key.dpapi，由 Windows DPAPI CurrentUser 加密。不要复制到 updates/public 或发给客户。assets/update-public-key.xml 是公开校验密钥，已嵌入客户端。不要随意重建密钥，否则旧客户无法接受新包；迁移发布电脑必须专门处理密钥迁移，单纯复制 DPAPI 文件不能保证解密。

服务只负责静态分发。程序自动更新失败日志位于本用户日志目录，原版备份保留在原 EXE 旁。文件权限不足时请把客户端解压到用户可写目录，不以关闭安全软件来解决。
