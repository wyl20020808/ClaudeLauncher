# macOS 1.7.17

- 兼容 Claude 4.4212.0：“同步到账号”（原“登记到账号”）放行已验证的新版本；可一次勾选多个账号，已有项目保持不变，完成后提示重启生效。
- 用量读取更稳：长对话不再挡住用量按钮；遍历不完整时仍按保守规则拒绝有歧义的结果。
- 新增“同步配置…”（账号页）：在账号之间同步 Claude Code 的 settings.json、CLAUDE.md、skills、agents、commands、output-styles；默认以链接方式同步，之后修改来源自动跟随；不碰 .claude.json 与凭据，含密钥的 settings.json 会被拒绝。
- 新增“用量趋势”（实例页）：近 7 天曲线、按当前速度估算用完时间、建议下一个账号；只用启动器已观察到的数值。
- 登录时启动改为开关；新增英文界面（设置 → 外观 → 界面语言）。
- 可靠性：取消更新后立即重试不再被旧任务干扰；安装后重新打开失败会恢复旧版；日志存储拒绝符号链接与异常文件，写入失败会提示，清空失败不丢日志。

不新增 Claude／Anthropic 访问。固定签名证书不变；Windows 安装包保持原版本。
