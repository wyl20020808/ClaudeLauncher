# Windows 1.9.0

界面改版和用量读取修复。

- 实例卡片：整张卡片点击即启动或打开该账号；“···”菜单保留启动、打开、关闭、删除。五小时和每周额度改成名字旁的小圆环，带本地倒计时。卡片背景换成四张无损高清插画，左侧白色渐变衬底保证文字清晰。
- 用量趋势页：原账号页改为用量趋势页，显示各账号近七天曲线、当前观察值和轮换建议。使用教程入口移到“设置 → 关于”。
- 标题栏：Windows 11 下主窗口标题栏跟随应用主题（浅色／深色），旧系统保持原样。
- 用量读取修复：展开官方用量弹窗后立即读取，缺项时在 2 秒内最多补读 4 次；多个账号同时展开互不干扰。缺失的额度显示占位和原因；历史值只在悬停中标为“非当前额度”，Claude 重启后不再当作当前额度。只读到周值时五小时显示“≈0% 估算”，不进入趋势和提醒。日志只记原因和计数，不记控件文字或百分比。

不新增 Claude／Anthropic 访问，不读凭据，只读本机官方界面。程序和安装包仍未签名（Authenticode）。

未验证：安装后真实窗口中的点击、悬停和高 DPI 显示；新构建在真实界面持续读取用量（只在一次手动展开时读到两项）；英文界面下的读取；客户机。详见 [STATUS](STATUS.md)。
