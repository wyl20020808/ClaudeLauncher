# Windows 1.8.6（草稿）

修复 1.8.5 的同步会话在客户机上无法使用的两个问题。

- 账号目录是在提权运行或关闭 UAC 时建的（所有者为本机 Administrators 组），之后不提权运行时，启动和同步报“存储项不属于当前用户”。现在接受 Administrators 组；SYSTEM 和其他用户仍拒绝。
- 同步会话不再只认商店版 Claude 4.4212.0.0：不限版本，写入前检查目标账号的会话记录格式，格式变了才拒绝并提示。
- 同步写入前另外检查目标账号会话目录和项目目录的所有者，不属于当前用户时拒绝；打不开的会话记录算格式未知，不再放行。
- 内嵌教程同步更新了版本说明。

同步会话只在本机读写，不新增 Claude／Anthropic 访问。**同步会话在 Windows 上仍没有经过真实账号和 Claude 客户端实测，所有者规则只在临时目录上实测过，详见 [STATUS](STATUS.md)。** 程序和安装包仍未签名（Authenticode）。
