# Windows 1.9.5

修复删除账号时报“账号内容含链接，未删除任何尚未处理的目录：…\ClaudeCodeConfig\skills\caveman”。

- 原因：删除前检查遍历账号目录，遇到任何链接（符号链接、目录联接）就整体拒绝。skills 用 `mklink /J` 安装、或配置同步的链接模式，都会在账号里放链接，这类账号就删不掉。
- 现在：账号目录内部的链接不跟随、不阻止删除，随账号目录一起移入回收站（移走的是链接本身），链接指向的内容（如 `~/.claude/skills`、其他账号的文件）不动。账号目录本身或其上级是链接时仍拒绝；仍只移入回收站，不永久删除。

不新增 Claude／Anthropic 访问，不新增网络入口。程序和安装包仍未代码签名（Authenticode）。macOS 不涉及（macOS 删除只校验账号根目录，不遍历内部链接）。

验证：`build.ps1` 通过；删除自检改为在临时目录的账号内建目录联接指向另一个临时账号，删除后该账号移入回收站，联接指向的文件内容不变。
未验证：安装后用真实账号点击删除。
