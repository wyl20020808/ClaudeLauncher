# Windows 1.8.4

- 隔离检查未通过时改为警告：弹窗说明原因和风险，可以取消，也可以点“仍然继续”启动；每次都会重新检查和提醒。删除账号时仍然会停止；账号路径不是文件夹时也无法启动。网络环境检测不变。
- 配置同步链接的目标判定与 macOS 对齐：指向 `.claude.json`、`.claude` 内白名单之外的内容、账号数据及其上级目录的链接判为未通过；点开头的条目不再同步。
- 用量趋势移到账号管理页：表格下方显示建议条、每个账号的最新数值和近 7 天图；实例页不再有“用量趋势”按钮。
- 项目管理页按 macOS 结构重做；“识别并导入”现在能读取商店版 Claude 的本机记录。
- 5 小时限额：手动点开官方用量弹窗时读取更可靠。
- 删除账号时，若两个候选路径实际是同一目录（从 Claude 终端启动启动器时可能出现），不再报“删除未完整完成”。
- 一并发布此前未发布的 macOS 1.7.17 同步内容：配置同步、完整项目清单与导入、系统／浅／深主题、英文界面及可靠性修复。
