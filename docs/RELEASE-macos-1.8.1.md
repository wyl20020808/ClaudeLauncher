# macOS 1.8.1

同步 Windows 1.8.7～1.8.9 的会话同步改进：

- 同步列表以来源账号的官方会话记录为准：只列侧栏里还在的会话，归档的不再列出；改模型或回退留下的旧段不再变成重复的一条。会话按记录的工作目录归到清单里最深的项目，项目内 worktree 的会话也归到该项目。某一层记录目录不认识或读取出错时只跳过它。
- 按侧栏分组：同步窗口在项目下面再按来源侧栏的自建分组分一层（按侧栏顺序，未分组放最后），可整组勾选；副本标题前加「【分组名】」。同步完成后可选“打开并建分组”：启动器冷启动目标账号，在新 Code 会话输入框里填好整理分组的指令，由你检查后自己发送，那边的 Claude 用官方侧栏工具建分组。目标账号已有同名分组时直接放进去，不重复建；有多个同名分组时放进侧栏最前面那个（与 Windows 1.8.9 不同：Windows 遇到多个同名分组会跳过）。指令同时复制到剪贴板：账号启动较慢时 Claude 偶尔丢掉预填的文字，输入框为空就粘贴。目标账号已在运行或指令太长时只复制到剪贴板。
- 问题诊断：系统设置 → 关于、同步窗口、“没有可同步的会话”提示都能打开。只读检查，报告只有计数、原因和打码路径，保存在本机；可复制，或在浏览器里打开本项目 GitHub 的新建问题页（已预填），由你自己提交。

界面同步 Windows 1.8.9 之后的改动：

- 点整张账号卡片即可启动或打开；“···”只剩启动／打开、关闭、删除。“关闭”核对进程后发送正常退出请求（等同 ⌘Q），不强杀。
- 卡片上两个用量圆环（5-hour、weekly，60%／80% 分绿黄红）和本地倒计时；没观察到的项不显示。卡片换成四张高清无损插画。
- 侧栏“账号管理”改为“用量趋势”，只保留趋势和建议；别名编辑、账号表、配置同步入口移除，已有别名照常显示。
- 教程入口移到“系统设置 → 关于 → 使用教程”。

为此列表会读取来源账号会话记录的 `cliSessionId`、`cwd`、`isArchived`、`sessionId` 和 `claude_desktop_config.json` 的侧栏分组，其余内容不保存。启动器不写官方分组数据、不代发消息，不新增 Claude／Anthropic 访问。固定签名证书不变。

未验证：真实鼠标键盘下的整卡点击、悬停与焦点，“关闭”对真实 Claude 的效果，高 DPI 外的显示器；目标账号运行中时的复制提示、官方侧栏工具建的分组在 macOS 重启后是否保留、同步窗口和诊断窗口的实际点击；详见 [STATUS](STATUS.md)。
