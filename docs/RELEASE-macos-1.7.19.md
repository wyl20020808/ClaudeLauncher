# macOS 1.7.19

- 新增“同步会话”：在项目页把会话同步到另一个账号接着聊。窗口按项目分组，可全选、按项目全选或逐条勾选，写入前可预览，生成和写入时有进度条。副本只保留对话文字和工具请求说明，不带账号信息、权限、工具结果和图片，标题后带“（副本 同步时间）”。两边之后各自继续，不会合并；重复同步会再生成一份。目标账号须已正常退出，目前只支持 Claude 4.4212.0。第一条消息由你发送。
- 移除“同步到账号”：同步会话时目录会自动出现在目标账号侧栏。已写入账号的空记录不处理。
- 账号管理页去掉表格内部滚动，鼠标滚轮不再卡住。
- “同步会话”和“识别并导入”旁边加了说明图标。

同步会话只在本机读写，不新增 Claude／Anthropic 访问。固定签名证书不变；Windows 安装包保持原版本，Windows 尚未实现同步会话。
