# macOS 1.8.6

- 新增：侧栏第二页「最近会话」取代「用量趋势」。各账号的会话按最后活动时间排在一起，每行显示标题、账号、项目和时间；每页 10 条，可“显示全部”。行内点“同步到…”选目标账号，直接进入与同步窗口相同的预览和确认（打开页面后 2 次点击到预览）。菜单里会标出“已是最新”“有更新，替换旧版本”“运行中，请先退出”。
- 读取只在点进这一页、点“刷新”或从这一页同步完成后各一次；启动器启动时恢复到这一页不读取，只显示“加载最近会话”。读取范围与同步窗口相同，不读对话正文、凭据、Cookie 或组织标识，结果只在内存，退出即丢弃。
- 移除：用量趋势页停止记录；旧的趋势数据不读、不写、不清除。

不新增 Claude／Anthropic 访问，固定签名证书不变；Windows 安装包沿用当前版本（Windows 版最近会话页尚未编译验证，未随本版发布）。
