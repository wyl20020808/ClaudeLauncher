# Windows 1.8.5（草稿，未发布）

- 新增“同步会话”：在项目页把会话同步到另一个账号接着聊。窗口按项目分组，可全选、按项目全选或逐条勾选，写入前可预览，生成和写入时有进度条。副本只保留对话文字和工具请求说明，不带账号信息、权限、工具结果和图片，标题后带“（同步 时间）”。两边之后各自继续，不会合并；重复同步会再生成一份。目标账号须已正常退出，并已从启动器打开过、创建过一次本地会话。第一条消息由你发送。目前只支持商店版 Claude 4.4212.0.0。
- 新增新手教程：第一次打开时自动播放一次互动引导，升级用户也会看到一次，可以随时跳过；引导期间不会启动账号，也不会改动数据。
- 新增永久入口：侧栏底部“使用教程”，可选软件内播放或查看文档教程。文档内嵌在程序里，在本机显示，不联网。
- 账号管理页去掉表格内部滚动，鼠标滚轮不再卡住。
- “同步会话”和“识别并导入”旁边加了说明图标。

同步会话只在本机读写，不新增 Claude／Anthropic 访问。**同步会话在 Windows 上没有经过真实账号和 Claude 客户端实测，只校对过文件格式，详见 [STATUS](STATUS.md)。** 程序和安装包仍未签名（Authenticode）。
