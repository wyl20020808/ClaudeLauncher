# Windows 1.8.5

同步 macOS 1.7.19～1.8.0。

- 新增“同步会话”：在项目页把会话同步到另一个账号接着聊。窗口按项目分组，可全选、按项目全选或逐条勾选，写入前可预览，生成和写入时有进度条。副本只保留对话文字和工具请求说明，不带账号信息、权限、工具结果和图片，标题后带“（同步 时间）”。目标账号须已正常退出，并已从启动器打开过、创建过一次本地会话。第一条消息由你发送。目前只支持商店版 Claude 4.4212.0.0。
- 同步过的会话以最新版本为准：合并成一行，显示“新增”“有更新”或“已是最新”。有更新的默认勾选，直接替换目标里的旧版本，旧版本移到回收站；目标比来源新时拒绝。升级前没有的关联不按标题猜测。
- 新账号同步提示：用启动器新建的账号登录、建过一个本地会话并正常退出后，询问一次是否把其他账号的项目和会话同步过来。
- 目标账号登录过多个账号或组织时，点击同步后在本机读一次它当前的组织，只写进同名目录；读不到或对不上时拒绝并说明原因。
- 用量：只读到周限额时，五小时显示 0%（估算），悬停有说明。
- 新增新手教程：第一次打开时自动播放一次互动引导，升级用户也会看到一次，可以随时跳过；引导期间不会启动账号，也不会改动数据。
- 新增永久入口：侧栏底部“使用教程”，可选软件内播放或查看文档教程。文档内嵌在程序里，在本机显示，不联网。
- 账号管理页去掉表格内部滚动，鼠标滚轮不再卡住。
- “同步会话”和“识别并导入”旁边加了说明图标。

同步会话只在本机读写，不新增 Claude／Anthropic 访问。读取组织时用当前 Windows 用户的 DPAPI 解出 Claude 的 Cookie 密钥，只解 `lastActiveOrg` 这一项，不输出、不保存（2026-11-04 用户授权，见 AGENTS.md）。**同步会话在 Windows 上没有经过真实账号和 Claude 客户端实测，只校对过文件格式并用合成数据自检，详见 [STATUS](STATUS.md)。** 程序和安装包仍未签名（Authenticode）。
