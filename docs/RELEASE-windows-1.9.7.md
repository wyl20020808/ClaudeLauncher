# Windows 1.9.7

同步副本的标题和“打开并建分组”的指令，与 macOS 1.8.7 相同（规格见 SPEC「同步会话 · 侧栏分组」）。

- 副本标题不再加「【分组名】」。以前同步留下的同组前缀，只在带同步后缀的旧副本再次同步时去掉；去掉后为空或全是空白时保留原样。你自己起的标题（没有同步后缀）不动。
- 来源未分组时，用关联版本里唯一的分组判断旧前缀；分组冲突或未知时不动。这个分组只用于标题，不影响分组展示和建组清单。
- 每条副本写入成功后，在设置目录 `session-plain-titles.json` 记「账号号:会话ID」（不存标题），有记录的副本以后不再去前缀；恢复默认设置不清除。
- 建组指令与 macOS 逐字相同：工具不限；查全分页列表，无法确认所在分组的先不移动；不直接读写 Claude 的本地账号文件；工具或系统的授权确认由用户完成。不再让 Claude 改标题。

不新增 Claude／Anthropic 访问，不新增网络入口，不读凭据、Cookie 或组织标识。程序和安装包仍未代码签名（Authenticode）。

验证：`build.ps1` 通过——LauncherTests 452、SyncTests 179、SessionSyncTests 458、TutorialTests 80、自检 331；`test-install.ps1` 3 个场景通过。测试只用合成数据。
未验证：GUI 手动测试、真实账号同步、官方 Claude 执行新指令；删除旧英文 key 后的 macOS 自检需在 Mac 上复跑。
