# macOS 1.7.9

用量来源改为 Claude Code 已有界面，停止读取旧用量历史。按官方主进程和固定账号目录对应五小时、周限额，分别标注最近观察时间。

正常查看官方用量时，启动器被动记录已显示的数据；关闭弹窗后仍可查看最近观察值，重启启动器后校验归属再恢复。账号、进程或身份状态变化时隐藏，未观察到的项目显示“—”，不从其他账号补位。

不自动点击、不触发官方查询、不读取登录凭据或访问 Claude Safe Storage。需要已有辅助功能权限。周限额首次记录依赖官方控件曾经可读，不能取得尚未暴露的数据；观察时间不是服务端更新时间。

固定签名证书保持不变。Apple 芯片与 Intel 自检、控件及持久化测试通过；真机五小时／周限额与官方已展开弹窗一致，正常退出并重启启动器后两项恢复为“上次显示”。关闭弹窗后的合并保留由合成控件测试验证。Windows 安装包沿用原版本。
