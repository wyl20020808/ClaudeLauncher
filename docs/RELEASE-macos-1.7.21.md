# macOS 1.7.21

- 新账号同步提示：用启动器新建账号后，登录、建一个本地会话并正常退出，启动器会询问一次是否把其他账号的项目和会话同步过来。默认勾选全部原始会话，之前同步过的副本不勾选；写入前仍要预览和确认，写入的是清理副本。账号刚创建时还不能同步，因为要等登录后才有写入位置。升级前已有的账号不会弹提示，继续用项目页的“同步会话…”。
- 用量：只读到周限额时，五小时显示 0%（估算），悬停有说明；展开官方用量弹窗后按官方显示更新。

旧版“同步到账号”留在账号里的空记录不处理。不新增 Claude／Anthropic 访问。固定签名证书不变；Windows 安装包保持原版本，Windows 尚未实现同步会话。
