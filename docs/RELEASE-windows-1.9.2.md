# Windows 1.9.2

跟上 macOS 1.8.1～1.8.3 的界面和同步改动。

- 用量提醒只提示：五小时用量达到阈值时只说明该账号已用多少，不再推荐其他账号，卡片上不再有“切换到账号”按钮。
- 用量趋势图：相邻两次记录间隔超过额度窗口（5 小时线 5 小时，周线 7 天）时断开，不再画跨天的斜线。趋势页与其他页面对齐。
- 页面精简：各页去掉副标题和说明小字；项目管理页的同步会话、识别并导入、添加目录、刷新四个按钮挪到标题旁边，说明改为按钮里的 i 图标，点 i 查看。日志页底部只显示条数。
- 按侧栏分组建分组：目标账号已有同名分组就直接放进去；有好几个同名分组时放进侧栏最前面那个，不再跳过。
- “打开并建分组”时指令同时复制到剪贴板。账号启动较慢时输入框可能是空的，粘贴即可。
- 英文界面：带百分号的文字（如用量提醒）也有英文了。
- 同步会话判断项目内路径更严：系统拒绝解析的目录链接按项目外处理，不再按字面算作项目内。

不新增 Claude／Anthropic 访问，不新增网络入口。程序和安装包仍未签名（Authenticode）。

未验证：安装后真实窗口的点击（i 图标、项目页按钮）、英文界面实际宽度和高 DPI；真实账号的用量提醒、冷启动后剪贴板内容和同名分组复用效果。
