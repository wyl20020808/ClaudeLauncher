# macOS 1.8.3

- 修复：启动账号时误报“账号存储隔离检查未通过：存储文件有硬链接”。Claude Code 会把内容相同的检查点备份在同一账号的不同会话之间做成硬链接，这不是账号之间共用数据。现在这类链接的所有名字都在本账号 `ClaudeCodeConfig/file-history` 内时放行；其他位置的硬链接、通往账号外的链接仍然拒绝。
- 修复：从账号 02～10 的 Code 终端里运行启动器时，账号 01 会沿用那个账号的配置目录，导致 01 的 Code 会话记录写错位置，重开后显示“在磁盘上未找到会话”。现在启动 01 前会清除该环境变量。

只检查文件元数据，不打开文件内容。不新增 Claude／Anthropic 访问，固定签名证书不变；Windows 安装包沿用当前版本。

未验证：安装后在启动器里真实启动账号 02，以及从 02 的 Code 终端启动 01。
