# Windows 1.9.8

修复同一会话在两个账号间来回同步时，已经追加消息却仍显示“已是最新”的问题。“同步会话”和“最近会话”使用同一套判断。

- 每次成功同步后，启动器在本机分别记下来源和目标的文件大小、修改时间和同步版本号。旧关联在升级后首次成功同步时补记。
- 两端都有改动且修改时间相同时，启动器会提示无法判定先后，保留两份内容。预览后目标大小或修改时间变化时，本次替换也会停止。
- 如果文件被等长改写且修改时间保持原值，这些元数据无法识别该改动。

本次随附 macOS 1.8.7。往返同步修复仅适用于 Windows。测试使用临时账号和合成会话，客户机实际同步仍待验证。
