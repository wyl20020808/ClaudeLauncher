# macOS 1.8.0

修复账号登录过多个账号或组织后，无法同步会话到该账号的问题：

- 目标账号有多套账号／组织记录目录时，点击同步后读取一次它当前的组织（`lastActiveOrg`），只写入同名组织目录。读不到、没有同名目录、同一组织出现在两个账号目录下或目录不安全时拒绝，不猜测。
- 这一步可能弹出系统钥匙串提示。拒绝后不会写入，重新打开启动器才会再次询问。目录唯一或没有目录时不访问钥匙串。
- 问题在预览之前提示，不用等确认后才报错；错误文案说明实际原因。
- 一条都没写入时，不再提示“会出现在侧栏”。

版本号自此按十进制进位：每段 0～9，1.8.9 之后是 1.9.0。

用户授权新增本机解密 `lastActiveOrg` 的用途（见 AGENTS.md），组织标识不输出、不持久化。不新增 Claude／Anthropic 访问。固定签名证书不变；Windows 安装包保持原版本，Windows 尚未实现同步会话。
