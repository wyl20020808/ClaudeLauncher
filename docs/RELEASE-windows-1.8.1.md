# Windows 1.8.1

- 本地界面用量：实例卡片显示「5小时限额」「周限额」的百分比与观察时间，来自 Claude Code 页面上已经显示的用量按钮。只在查看实例页时读取一次（切回启动器、点进实例页或在实例页点击），不点击、不展开、不联网，不读 Cookies、登录信息或聊天内容。
- 官方按钮一次只显示一项（五小时窗口进行中显示五小时，未开始时显示每周）；另一项保留上次观察值和原时间。观察记录保存在启动器自己的 `usage-observations.json`，Claude 重启或账号变化后不再沿用。
- 「系统设置 → 外观」新增「显示本地界面用量」（默认开），关闭后停止读取并删除观察记录。
- 限制：不核对组织，同一账号内切换组织后，Claude 重启前可能显示上一组织的数值；不监听官方弹窗展开；需要该账号的 Claude 窗口停在 Code 页面。首次读取会让该 Claude 进程开启本机网页辅助功能，直到它退出。

只做本地操作，不向 Claude／Anthropic 发请求，不读取登录凭据。安装包未做代码签名，首次运行可能出现 SmartScreen 提示。
