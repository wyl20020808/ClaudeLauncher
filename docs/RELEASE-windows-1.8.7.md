# Windows 1.8.7

修复同步会话列表不按项目、把归档会话也列出来的问题。

- 列表改为以来源账号的官方会话记录为准，只列侧栏里还在的会话：归档的不再列出；同一会话改模型或回退后留下的旧段不再变成重复的一条。
- 会话按记录的工作目录归到公共清单里最深的那个项目；在项目 worktree 里聊的会话也归到该项目，以前会漏掉。
- 为此列表会读取来源账号会话记录里的 `cliSessionId`、`cwd`、`isArchived` 三个字段，其余内容不保存。

同步会话只在本机读写，不新增 Claude／Anthropic 访问。**同步会话在 Windows 上仍没有经过真实账号和 Claude 客户端实测；本机没有归档记录，排除归档只在合成数据上验证，详见 [STATUS](STATUS.md)。** 程序和安装包仍未签名（Authenticode）。
