# macOS 1.8.5

- 新增：官方更新后的重开提示。多开时账号“自己关掉”，多半是 Claude 官方的静默更新：窗口空闲约 10 分钟、没有进行中的任务时，官方会自动退出并安装更新，更新后只重新打开默认账号 01，其他账号不会回来。现在启动器发现某个账号退出后官方版本变了，会记日志、显示窗口内提示，并在启动器处于前台时逐个账号询问一次“重新打开账号 NN／不用了”。点“重新打开”走普通启动流程（网络环境检测、存储校验）；启动器不会自己启动账号。通过启动器“关闭”退出的那次不提示。

只读进程列表和官方 `Claude.app` 的版本号，不读官方日志或账号数据，不改官方更新设置。不新增 Claude／Anthropic 访问，固定签名证书不变；Windows 安装包沿用当前版本。

验证：arm64 与 x86_64 自检全部通过（新增官方更新退出判断的合成测试）。未验证：真实官方更新时的提示和重新打开（要等下一次官方更新）；启动器没在运行期间发生的更新不会提示。
