# macOS 1.7.23

修复 1.7.22 会话同步的问题（外部审查发现）：

- 替换时不再覆盖其他会话的同名记录；记录目录里有硬链接等不安全文件时拒绝替换，查找时其他记录只读开头的标识。
- 移动旧版本前再次核对目标文件，期间有变化就停止。先更新记录再替换正文，记录失败时什么都没变。放回旧版本也失败时，明确提示旧版本在废纸篓。
- 版本比较精确到纳秒，同一秒内的修改不再被判为“已是最新”。
- 切换目标账号时，只撤销窗口自动勾选的行，保留手动勾选。新账号默认选择不再漏掉只剩一个的已关联副本。
- 同步关系逐条保存，中途退出不会让已写入的副本失去关联。
- 入口、教程和指南不再写“原会话不变”：同步过的会话会被最新版本替换。

不新增 Claude／Anthropic 访问。固定签名证书不变；Windows 安装包保持原版本，Windows 尚未实现同步会话。
