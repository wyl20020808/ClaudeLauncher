# Windows 1.8.0

同步 macOS 1.7.10～1.7.14 的规格：

- 联网更新默认关闭，只用本项目 GitHub Releases；开启并保存后每次打开启动器检查一次，也可手动检查。不再访问自建更新服务，删除 24 小时自动检查。
- 系统设置六个分类全部可用（草稿、保存、撤销、恢复默认），顶部分段标签与分组卡片布局；开机启动、恢复上次页面、刷新间隔、托盘图标、插画、日志上限、窗口内提示等。
- 账号页：搜索、状态筛选、本地别名、多选复制路径；无别名时显示本地 Claude Code 用户名。实例卡片只显示名称与运行状态。
- 日志保存到文件，重启和更新后保留；日志页按时间（默认最近 7 天）、实例、级别与全文筛选，数字页码。

只做本地操作，不向 Claude／Anthropic 发请求，不读取登录凭据。本地界面用量 Windows 版尚未接入。安装包未做代码签名，首次运行可能出现 SmartScreen 提示。
