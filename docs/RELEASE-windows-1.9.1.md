# Windows 1.9.1

修复同步会话误报。

- 同步会话写入 0 条并提示“存储项是硬链接，已停止：…ClaudeCodeConfig\file-history\…”：Claude Code 续接或分叉会话时，会把检查点备份硬链接到新会话目录，这是官方正常行为。存储校验原先拒绝所有硬链接，现在只要硬链接的所有名字都在同一账号目录内就放行；与账号目录外、其他账号共用或内外混合的硬链接仍拒绝，提示改为“存储项与账号目录外的文件共用硬链接”。打开账号时的隔离检查警告同样不再因此出现。

不新增 Claude／Anthropic 访问，只读文件元数据（链接名），不打开文件内容。程序和安装包仍未签名（Authenticode）。macOS 暂未改，仍拒绝所有硬链接。

未验证：客户机上真实账号的同步（本机账号没有这类硬链接，只用合成目录自检）。
