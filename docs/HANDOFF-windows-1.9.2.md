## 需要 Windows 实现

### 1. 用量提醒只提示，不推荐切换账号（`285ba11`，macOS 1.8.2）

- 现状（Windows）：`LauncherUI.cs:1926` 提醒文本仍附“建议切换到账号 NN”；`LauncherUI.cs:2089` 卡片仍有“切换到账号 NN”按钮。
- 要求：五小时用量达到阈值只在状态栏、日志、窗口内提示中说明，不推荐其他账号，不显示切换按钮，也不附交接文档提示。去重状态 `usageAlertState` 不变。
- SPEC「消息通知」和文末 Windows 段已写成“只提示，不推荐或切换账号”，代码要按它改。相关测试一并调整。

### 2. 趋势图跨长空档断线（`285ba11`）

- 现状：`LauncherUI.cs` 趋势图 `runs` 只在数值回落时断开。
- 要求：两个相邻观察点的间隔超过该额度窗口（五小时线 5 小时，周线 7 天）时也新起一段，不画跨天的斜线。参考 `src/UsageTrend.m` 的 `drawRect:`。加测试或离屏预览核对。

### 3. 页面去说明文字、项目页按钮上移（`285ba11`）

- 去掉各页面副标题（Windows `PageTitled` 的 `subtitle`）、设置页每项下方的说明和灰色说明框、项目管理页的共享目录提示框和底部说明；日志页底部只显示条数。辅助功能授权状态、数据目录路径保留（Windows 无辅助功能项则忽略）。
- 项目管理页：同步会话、识别并导入、添加目录、刷新四个按钮放在标题那一行，按文字宽度排；原来的说明改成按钮里面的 i 图标，点 i 看说明。日志、设置、趋势页的内容上移，与项目页对齐。
- 删掉的说明文字如果有英文翻译，一并清理。

### 4. 侧栏分组：已有同名分组就复用（`b00bb7f`，用户 2026-11-04 要求）

- 现状：`SidebarGroups.cs:66` `InstructionHead` 第 2 条是“有多个就跳过这一组并说明”。
- 要求：第 2 条换成 macOS 原文：“目标侧栏里已有同名分组就直接放进去，不要再建同名分组；有多个同名分组时，放进“列出分组”结果里排在最前的那个，并在汇报里说明；没有同名分组才新建。”（`src/SessionSync.m:174`）。英文翻译同步。
- 测试：指令含“不要再建同名分组”“排在最前的那个”，不含“有多个就跳过”。
- SPEC 第 254 行附近“【macOS，仅 macOS，Windows 未改】”改为两端一致。

### 5. 冷启动预填分组指令时同时复制到剪贴板（`6d3635c`）

- 原因：真实账号测试中，冷启动较慢时 Claude 会丢掉预填的 `q`（首个页面加载被替换后才交出 q），输入框为空。
- 现状：Windows `FinishSessionSync`（`LauncherUI.cs:958` 附近）只在指令过长、不能预填时才复制。
- 要求：能预填时也把指令写入剪贴板；完成对话框加一句“指令同时会复制到剪贴板。账号启动较慢时输入框可能是空的，粘贴即可。”复制失败只记日志，不阻止打开。
