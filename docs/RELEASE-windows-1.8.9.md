# Windows 1.8.9

同步会话支持按 Claude Code 侧栏的自建分组。

- 同步窗口：项目下面再按来源账号侧栏的分组分一层（按侧栏顺序，未分组放最后），可以整组勾选。分组只读自来源账号的 `claude_desktop_config.json`。
- 副本标题前加「【分组名】」，在目标账号里能认出、能搜索。
- 原生分组：同步完成后，有分组时可选“打开并建分组”。启动器用官方 `claude://code/new` 链接在目标账号新建 Code 会话，输入框里预填整理分组的指令（分组名和副本的侧栏 ID）。用户检查后自己按发送，由那边的 Claude 用官方侧栏工具建分组、移入副本；会用掉一条消息的额度。同名分组只有一个就复用，副本已在别的分组里的不动。指令太长时改为复制到剪贴板。

启动器不写任何官方分组数据（本地写入会被 Claude 启动时覆盖），不代发消息，不新增 Claude／Anthropic 访问。完整流程已由用户在两个真实账号上实测；客户机未验证，详见 [STATUS](STATUS.md)。程序和安装包仍未签名（Authenticode）。
