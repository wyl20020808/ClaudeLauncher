五小时和周限额分别显示已用百分比及观察时间。五小时按钮在弹窗关闭时通常仍可读；周限额只有在你正常展开官方用量弹窗、控件可读并被启动器观察到时才能取得。启动器绝不会自动打开弹窗或发送查询。没观察到就显示“—／尚未观察到”，不会假装是 0%。五小时额度重置后、还没发第一条消息时，官方按钮只显示周额度：启动器此时更新周额度，五小时仍显示上次观察值；手动点开官方用量弹窗即可记录新的五小时值。
卡片上的时间是本地观察时间，不是服务器更新时间；没有重新观察到的周限额保留原时间，不会因五小时更新而换上新时间。悬停可看完整日期和官方重置说明。关闭弹窗后仍显示两项最近观察值；Claude 退出后卡片也继续显示最后一次观察值，标“Claude 未运行 · 上次记录”。重启启动器后会读取自己保存的观察记录，重新核对账号、官方进程及组织指纹，匹配后恢复；Claude 进程重启、账号或组织指纹变化则重新获取。切换同账号的 Code 对话不会让已观察的周限额丢失。

账号配置同步（Claude Code）
02～10 的 Claude Code 使用各自独立的配置目录，默认读不到 01 的 ~/.claude。账号页“同步配置…”可选来源账号和一个或多个目标账号，同步 settings.json、CLAUDE.md 等顶层说明文件，以及 skills、agents、commands、output-styles 中的条目。这些条目以链接方式同步时可以正常通过账号存储隔离检查。配置目录其他位置出现链接，或链接指向账号数据时，启动前会弹出警告说明风险，可以取消，也可以点“仍然继续”启动；删除账号时仍会停止。
默认“以链接方式同步”：目标里放的是指向来源文件的链接，之后改来源，目标立即生效，无需再次同步；两个账号共用同一份文件，在目标里修改也会改到来源。关闭该选项则复制一份。默认只补目标缺少的条目；“不同”的条目需勾选覆盖才替换，旧内容移到废纸篓；覆盖时“相同”的拷贝也会改成链接。
不复制 .claude.json、登录凭据、会话、历史、项目记录和插件；settings.json 含密钥类字段时拒绝同步。MCP 服务器配置存于 .claude.json，需在各账号自行添加。完成后新开的 Code 会话生效，运行中的账号建议重启。

登录
从账号卡片“···”选择“登录 / 重新登录保护…”。新建实例时弹出提醒：可“直接创建”（其他 Claude 保持运行，登录后请核对身份），或“进入登录保护”。请保存工作并正常退出其他 Claude 实例，等待其他账号的检查和启动完成，再确认“保护并打开”。不会替你退出、登出或强杀 Claude。
保护期间只允许从启动器打开目标账号，暂不允许新建其他实例或删除受保护账号。请自行登录并核对浏览器及 Claude 中的身份。完成登录或取消浏览器登录流程后，点击“结束登录保护”并确认。正在检查或启动时，需等待操作完成后再结束保护。
保护状态在重开启动器后仍保留。若从 Dock、终端等外部入口打开其他 Claude，启动器会提示停止登录，但无法阻止外部启动或拦截系统回调。未验证两个真实账号登录是否串号。

Code 配置状态
01 显示“Code 默认”，沿用 ~/.claude 等默认用户配置，与普通终端 CLI 共用。
02～10 未运行显示“Code 待启动”；外部启动或旧实例显示“Code 未确认”。保存工作后正常退出该 Claude，再从启动器启动，会指定各自账号目录内的 ClaudeCodeConfig。
“Code 已指定”只说明本次启动器向核实的新进程指定了独立配置，不表示已验证 Code 的实际写入。重开启动器后，已有实例会保守显示“未确认”。不会读取进程环境变量，也不会移动、合并或删除旧记录。两个不同编号仍可能由用户登录同一个真实账号，启动器不读取身份来判断。

后台检查
打开和删除前，后台只检查存储元数据，不读取账号内容。同账号检查期间不能重复操作，其他账号仍可使用。检查完成会重新核对进程、登录保护和路径；原实例若已经退出或被替换，不会自动重启或静默切到新实例。无法识别官方进程时仍暂停全部启动操作，避免重复启动。

项目管理（本机公共入口）
“同步会话…”：把本地会话以清理副本放到另一个账号的同一项目下继续工作。窗口按项目分组，可全选、按项目全选或逐条勾选；选好目标账号，看预览，点同步。副本只保留对话文字和工具请求说明，不带账号信息、权限、工具结果和图片；邮箱、常见密钥和项目外路径按规则替换，其他私人信息请在预览里自己确认。目标账号须已正常退出，目前只支持 Claude 4.4212.0。两边之后各自继续，不会合并，再同步会生成新副本。第一条消息由你发送，计入目标账号额度；项目未受信任时官方会请你确认。
新增“识别并导入”：检查所有已创建的 01～10 账号，包括未运行账号和仍保留在本机的历史记录。识别完成后，核对目录、勾选需要的项目，再点“导入所选”。重复目录不重复添加；已有名称、分组、排序和上次账号保留。取消不会写入清单。
只读取支持格式的目录前缀，不读取后面的正文、凭据或项目文件，不改客户端记录，不启动／退出账号，不联系官方服务。它只汇总启动器的公共入口，不同步 Claude 原生侧边栏、文件或会话。
