Claude 启动器 1.6 / build 7（macOS 隔离加固，2026-10-28；未发布）

安装：打开 DMG，把「Claude 启动器」拖到「应用程序」。首次打开若提示无法验证开发者，在 Finder 中右键应用选「打开」，或到「系统设置 → 隐私与安全性」点「仍要打开」。日常不需要终端、Python 或 Node.js。支持 Apple 芯片与 Intel，macOS 12 及以上。
只显示本机已有的账号，每个账号一张卡片，主按钮为创建、启动或打开；正在启动时按钮禁用。“+ 新建实例”会创建第一个尚未使用的编号。卡片右侧“···”可在 Finder 中显示或复制账号目录。卡片上的“5小时限额”“周限额”为预留区域，目前未接入数据，不读取账号信息。关闭启动器不会退出 Claude。

账号目录
01：~/Library/Application Support/Claude（沿用默认账号，不传覆盖参数）
02：~/Library/Application Support/Claude-Second
03～10：~/Library/Application Support/Claude-Profile-03 至 Claude-Profile-10
悬停主按钮可查看完整目录。启动器不会自动删除、迁移或覆盖数据。 删除：点卡片右侧“···”→“删除该实例…”，确认后整个账号目录移到废纸篓（可恢复）。账号 01 不能删除；运行中的账号需先在 Claude 中正常退出（⌘Q）。

登录
从账号卡片“···”选择“登录 / 重新登录保护…”。新建实例时弹出提醒：可“直接创建”（其他 Claude 保持运行，登录后请核对身份），或“进入登录保护”。请保存工作并正常退出其他 Claude 实例，等待其他账号的检查和启动完成，再确认“保护并打开”。不会替你退出、登出或强杀 Claude。
保护期间只允许从启动器打开目标账号，暂不允许新建其他实例或删除受保护账号。请自行登录并核对浏览器及 Claude 中的身份。完成登录或取消浏览器登录流程后，点击“结束登录保护”并确认。正在检查或启动时，需等待操作完成后再结束保护。
保护状态在重开启动器后仍保留。若从 Dock、终端等外部入口打开其他 Claude，启动器会提示停止登录，但无法阻止外部启动或拦截系统回调。未验证两个真实账号登录是否串号。

Code 配置状态
01 显示“Code 默认”，沿用 ~/.claude 等默认用户配置，与普通终端 CLI 共用。
02～10 未运行显示“Code 待启动”；外部启动或旧实例显示“Code 未确认”。保存工作后正常退出该 Claude，再从启动器启动，会指定各自账号目录内的 ClaudeCodeConfig。
“Code 已指定”只说明本次启动器向核实的新进程指定了独立配置，不表示已验证 Code 的实际写入。重开启动器后，已有实例会保守显示“未确认”。不会读取进程环境变量，也不会移动、合并或删除旧记录。两个不同编号仍可能由用户登录同一个真实账号，启动器不读取身份来判断。

后台检查
打开和删除前，后台只检查存储元数据，不读取账号内容。同账号检查期间不能重复操作，其他账号仍可使用。检查完成会重新核对进程、登录保护和路径；原实例若已经退出或被替换，不会自动重启或静默切到新实例。无法识别官方进程时仍暂停全部启动操作，避免重复启动。

仍共享的资源
目录隔离不能隔离系统权限、应用级加密设施、浏览器回调、日志、用户项目、网络和本地服务。不同账号尽量使用各自项目副本及服务端口；操作同一个项目时，代码、项目规则、MCP 配置和本地权限文件仍可能相互影响。启动器不自动复制项目或修改这些配置。

窗口恢复
按匹配主进程 PID 激活。恢复最小化窗口可能需要系统辅助功能授权。使用同一固定证书重建可保持签名身份；证书更换或使用 ad-hoc 签名可能需要重新授权。启动器不会修改系统权限。本轮真实窗口恢复未验证。

构建
源码见 src/main.m 和 scripts/build.sh。在项目根目录运行 SIGN_IDENTITY="ClaudeLauncher Local Signing" /bin/zsh scripts/build.sh，可传入独立验证输出目录。依赖 Xcode Command Line Tools，使用原生 AppKit；本机优先 MacOSX15.4.sdk。
日常打开 build/Claude 启动器.app。重建不会更换正在运行的启动器进程，需要退出启动器后重新打开；这不会退出已有 Claude 实例。旧 Claude 实例要采用新的启动配置，仍需你保存工作后自行正常退出并重新启动。
构建仅为启动器本身本地签名，复制官方图标，不复制或修改官方 Claude.app。交付面向本机 Apple Silicon，未做 Apple 公证。
历史版本测试记录与当前版本检查分开保留。
