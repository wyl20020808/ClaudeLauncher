Claude 启动器 1.6（开发构建；日常交付仍为 1.5）

双击「Claude 启动器.app」。日常不需要终端、Python 或 Node.js。
只显示本机已有的账号，每个账号一张卡片，主按钮为创建、启动或打开；正在启动时按钮禁用。“+ 新建实例”会创建第一个尚未使用的编号。卡片右侧“···”可在 Finder 中显示或复制账号目录。卡片上的“5小时限额”“周限额”为预留区域，目前未接入数据，不读取账号信息。关闭启动器不会退出 Claude。

账号目录
01：~/Library/Application Support/Claude（沿用默认账号，不传覆盖参数）
02：~/Library/Application Support/Claude-Second
03～10：~/Library/Application Support/Claude-Profile-03 至 Claude-Profile-10
悬停主按钮可查看完整目录。已有数据不会删除、迁移或覆盖。

登录
已移除“单独登录”入口和常驻保护说明。创建空账号空间时显示简短提醒。需要登录或换号时，请先保存工作并正常退出其他 Claude 实例，再自行登录并核对身份；浏览器登录回调仍可能切错实例。
兼容旧版已开启的登录保护：若保护仍生效，会显示状态和“结束登录保护”按钮，可在完成登录后解除；不会静默清除旧保护。
独立目录不等于多台电脑，不能保证隔离系统钥匙串、浏览器回调、Claude Code 配置、后台服务和文件权限。未读取登录凭据，未验证两个真实账号登录是否串号。

窗口恢复
按匹配主进程 PID 激活。恢复最小化窗口可能需要系统辅助功能授权。重建后本地签名变化，如授权失效，需要手动移除旧条目并添加当前应用；启动器不会修改系统权限。1.3 未重测最小化恢复和深色模式。

构建
源码见“源码/main.m”和“源码/build.sh”。在源码目录运行 /bin/zsh ./build.sh，可传入输出目录。依赖 Xcode Command Line Tools，使用原生 AppKit；本机优先 MacOSX15.4.sdk。
构建仅为启动器本身本地签名，复制官方图标，不复制或修改官方 Claude.app。交付面向本机 Apple Silicon，未做 Apple 公证。
历史版本测试记录与当前版本检查分开保留。

1.5：创建按钮蓝色，启动按钮暖棕色，打开按钮绿色；禁用状态灰色。
1.6：02～10 的 Code 标签页使用各自账号目录下的 ClaudeCodeConfig，不再与 01 共用 ~/.claude。已在运行的实例需正常退出后从启动器重新启动才生效；旧 Code 记录留在 ~/.claude，不迁移、不删除。钥匙串、登录回调、日志目录仍共享；要像两台电脑一样隔离，请用两个 macOS 用户账户。
1.6 界面（feature/ui）：改为水墨风布局，新增日志记录和系统设置页（显示辅助功能状态）；账号管理页为占位。界面固定浅色。
