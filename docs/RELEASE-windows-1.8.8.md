# Windows 1.8.8

新增问题诊断，方便排查“同步不全”“同步窗口只显示部分项目”这类问题。

- 入口：系统设置 → 关于 →「问题诊断」；同步窗口左下角「列表不全？问题诊断…」；“没有可同步的会话”提示里的「问题诊断…」。
- 只读检查：哪些项目在同步窗口里会显示、不会显示及原因（全部已归档、正文不在记录指向的位置、缺正文、只有旧段、没有会话）；记录目录里让启动器整层跳过的条目；打不开或格式不对的记录；项目搬家；各账号能否作为同步目标；最近的启动器错误。
- 报告只有计数、原因和打码路径（盘符加最后一级目录名），不含对话内容、会话标题和凭据；先在窗口里给用户看，保存在 `%LOCALAPPDATA%\Claude-MultiLauncher\logs\reports`（最近 10 份）。
- 发送由用户决定：「复制报告」「打开报告文件夹」，或「提交到 GitHub…」确认后在浏览器打开本项目的新建问题页（已预填），用户用自己的 GitHub 账号检查后提交。启动器不联网上传、不带令牌。
- 同步列表：某个记录目录读取出错时只跳过该目录，以前会让整个账号一条都不列。

不新增 Claude／Anthropic 访问。**诊断窗口的点击、复制和提交到 GitHub 未在 GUI 里实测；同步会话在 Windows 客户端的显示仍以用户本机测试为准，详见 [STATUS](STATUS.md)。** 程序和安装包仍未签名（Authenticode）。
