# Windows 1.8.2

- 本地界面用量：你在 Claude 里手动点开官方用量弹窗时，启动器读一次弹窗，同时更新「5小时限额」「周限额」（启动器窗口不用开着，Claude 需在前台）。启动器不替你展开弹窗，也没有定时读取。
- 弹窗关着时，仍只读官方按钮上显示的那一项；另一项保留上次观察值和原时间。
- 只在含官方用量设置链接的弹窗内读取文字与进度，不读聊天内容；只注册展开状态变化通知，不点击、不联网，不读 Cookies 或登录信息。
- 限制：不核对组织；需要该账号的 Claude 窗口停在 Code 页面。

只做本地操作，不向 Claude／Anthropic 发请求，不读取登录凭据。安装包未做代码签名，首次运行可能出现 SmartScreen 提示。
