# macOS 1.8.7

- 同步副本标题不再加「【分组名】」，不论之后是否建分组（2026-11-17 用户要求）。以前版本留下的同组前缀在再次同步或替换同步时去掉：只处理带同步后缀的旧副本，且前缀与来源分组完全一致；来源没有分组时，只借用同一关联里唯一已知的分组。去掉后只剩空白时保留原样；用户自己起的标题（例如「【门店】毛利分析」）不改。新版写出的副本在启动器偏好 `sessionSyncPlainTitles` 里记 `账号号:会话ID`（不存标题、分组名或正文），以后不会再被当成旧副本清理。
- “打开并建分组”的预填指令不再限制 Claude 用哪些工具（此前只许用侧栏和改标题工具，官方“列出分组”看不到每条会话所在分组，那边的 Claude 会停下来请求用“列出会话”）。指令不再要求改标题；新增：查全分页或有数量上限的列表、无法确认所在分组的先不移动、不直接读写 Claude 本地账号配置或数据文件、官方授权确认仍由用户处理。
- 同步窗口的分组提示和预览不再说“会加分组名”。

不新增 Claude／Anthropic 访问，固定签名证书不变；Windows 安装包沿用当前版本（Windows 只跟进了第一轮改动，未编译，未随本版发布）。

验证：arm64 与 x86_64 `--self-test` 全部通过（含新增的标题迁移往返测试：中英文、连续同步、JSONL 与记录一致、未分组旧副本回同步、关联分组冲突不猜）；`--ui-self-test` 通过（偏好标记去重、重新读取、恢复默认设置保留）。独立复现程序：「原标题」→「原标题（同步…）」；「【甲】原标题（同步 10/26 12:00）」→「原标题（同步…）」；「【门店】毛利分析」与「【甲】（同步…）」保持原样。未验证：真实账号里的同步、目标账号 Claude 实际执行新指令的效果。
